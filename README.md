# jQuery DOM Manipulation & Event Handling Demos

A collection of interactive HTML and jQuery examples exploring core DOM manipulation, content updates, element wrapping, and user event listeners.

## Covered Concepts

- **DOM Insertion & Positioning:** `append()`, `appendTo()`, `prepend()`, `prependTo()`, `after()`, `before()`, `insertAfter()`, `insertBefore()`
- **DOM Removal & Replacement:** `empty()`, `remove()`, `replaceWith()`, `wrap()`, `wrapAll()`
- **Content & HTML Helpers:** `text()`, `html()` (`GetTextDemo.html`, `SettextDemo.html`, `HtmlFunDemo.html`)
- **Event Handling:** `click`, `dblclick`, `keypress`, and `change` event listeners (`click.html`, `dblClick.html`, `keypress.html`, `changeEvent.html`)

## How to Run

1. Clone or download the repository.
2. Open any `.html` file directly in your browser (uses the bundled `jquery-3.6.0.js`).
